## 📖 Project Overview

EventHub is a mobile-first event booking application prototype designed to simplify the ticket booking experience. The project follows the Design Thinking methodology and focuses on intuitive navigation, modern UI design, accessibility, and interactive user flows.

---

## ✨ Features

- Splash & Onboarding
- Secure Login
- Personalized Home Dashboard
- Event Search & Categories
- Event Details
- Interactive Seat Selection
- Secure Payment
- Booking Confirmation
- Smart Animate Transitions

---

## 📱 Prototype Flow

Splash → Login → Home → Event Listing → Event Details → Seat Selection → Payment → Booking Confirmation

---

## 🎨 Design System

- Primary Color: #6C63FF
- Typography: Poppins & Inter
- Mobile-first Layout
- Card-based UI
- Rounded Components
- Consistent Navigation
